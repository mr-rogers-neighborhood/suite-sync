# Accessibility

This repository ships no user interface. It is the sync protocol and the relay server, so the
accessibility work that applies to it is different in kind from the apps:

- **Nothing here is visual.** There are no colours, targets, focus rings or animations.
- **Errors are text.** A refusal says what was refused in a sentence, because the only way to
  see it is a log or a client that shows one.
- **The clients are where the interface lives.** For those, see the statement in
  [suite-canvas](https://github.com/mr-rogers-neighborhood/suite-canvas/blob/main/ACCESSIBILITY.md),
  [suite-planner](https://github.com/mr-rogers-neighborhood/suite-planner/blob/main/ACCESSIBILITY.md)
  and [suite-budget](https://github.com/mr-rogers-neighborhood/suite-budget/blob/main/ACCESSIBILITY.md).
- **The launcher's statement** is in
  [suite-start](https://github.com/mr-rogers-neighborhood/suite-start/blob/main/ACCESSIBILITY.md),
  and it is where the shared contrast gate lives.
